# Примерочная — итоговые файлы

Всё, что идёт в игру, лежит здесь. Папки `test/` и `test2/` — черновики и стопки Codex.

| Папка | Что лежит | Кто кладёт |
|---|---|---|
| `character/` | персонаж: `base` (бельё), `base_blink`, `base_happy`, `base_oops`, `hand_palm` (рука на поясе, лежит поверх одежды). PNG с прозрачным фоном, 1024×1536 | готово |
| `icons/` | иконки витрины «как в каталоге», белые (перекрашиваются в игре), очки — чёрные. PNG 512×512, прозрачный фон | готово |
| `sources/` | **исходники для обводки**: картинка, на которой обводится вещь. С неё же берётся рисунок вещи | готово |
| `masks/` | **ручные обводки**: `<вещь>_mask.png` — `sources/<вещь>.png` с вещью, залитой `#FF00FF` | Дима |
| `replace/` | **что исчезает с тела под вещью**: `<вещь>_replace.png` — `sources/base.png`, где залито `#FF00FF` то, чего под этой вещью не существует (например, ноги под брюками) | Дима |
| `layers/` | слои вещей на персонаже (результат нарезки), белые, 1024×1536 | скрипт |
| `clip/` | маски видимости «нижний слой — верхняя вещь» | скрипт |
| `web/` | всё выше в лёгком webp для игры | скрипт |

## Обводка

1. Открыть `sources/<вещь>.png` (1024×1536, размер не менять).
2. На новом слое залить вещь `#FF00FF` целиком, вместе с чёрным контуром. Обводка = силуэт вещи,
   берётся как есть: где обводка шире нарисованной вещи, ткань и контур дорисовываются.
   Руку на поясе не закрашивать.
3. Экспорт PNG → `masks/<вещь>_mask.png`.

Исходники: `pants` = стопка 1 (брюки), `shoes` — полные туфли того же фасона, что в стопке (прежний вариант — `shoes_v1.png`), `shirt` — рубашка целиком на голом персонаже,
`tie` = стопка 4 (на голубой рубашке), `jacket` = стопка 5 (на рубашке с галстуком).

## Зона замены на теле

1. Открыть `sources/base.png` (персонаж в белье на белом фоне, 1024×1536).
2. Для наглядности можно положить сверху `sources/<вещь>.png` полупрозрачным слоем и потом скрыть.
3. Залить `#FF00FF` части тела, которые под вещью исчезают. Залитое пропадает, когда вещь надета;
   если зайти за край вещи, там будет видно фон, поэтому заливать точно по вещи или чуть внутрь.
4. Экспорт PNG → `replace/<вещь>_replace.png`. Без такого файла зона считается по форме вещи.

## Сборка (из корня репозитория)

```bash
python3 scripts/clothing-game-hand-masks.py pants shoes shirt   # слои по обводкам
python3 scripts/clothing-game-clip-masks.py                     # маски видимости
python3 scripts/clothing-game-export-web.py                     # webp для игры
```
Нужны Pillow, numpy, scipy. Вещи без ручной обводки (сейчас `shoes`, `shirt`, `tie`, `jacket`,
`glasses`) лежат в `layers/` из нарезки Codex.
