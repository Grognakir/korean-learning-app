# Передача контекста и журнал работ

Этот файл — общий источник контекста для всех моделей, работающих с проектом. Его нужно читать в начале задачи и обновлять после значимых изменений, особенно после публикации.

Не добавлять сюда пароли, ключи, токены и другие секреты.

## Как обновлять файл

1. Новые устойчивые особенности проекта добавлять в раздел «Постоянный контекст».
2. Незавершённые задачи поддерживать в разделе «Открытые задачи».
3. Выполненную работу записывать в начало журнала: дата, результат, коммит, проверки и состояние production.
4. Не писать «выложено на прод», пока не проверены все применимые этапы:
   - коммит отправлен в `origin/main`;
   - deployment рабочего Vercel-проекта завершился успешно;
   - изменения контента синхронизированы с production Supabase;
   - рабочий домен открыт и показывает новые данные.

Слова из `vocab_list` подсвечиваются в связанном тексте автоматически (`related_text_ref`), а в `grammar_point`/`grammar_exercise` — слова ВСЕХ `vocab_list` раздела; поэтому в `TextBlock.vocab` добавлять только формы, которые не ловятся основой (`교환` для 교환할, `중요` для 중요합니다 — «форма от X»), а в примеры упражнений — через `example.vocab`.

Если окончание или частица вросли в последний слог основы (`큰`, `갔`, `어렸`, `축구할`), слог подсвечивается вместе с ними; если окончание или частица — отдельный слог (`잘하는` → только `잘하`, `어렸을` → `어렸`), он не подсвечивается. В середине и в конце предложения одинаково. Выделения грамматических показателей (`emphasized`) этим правилом не меняются. Реализация — `chipEnd` в `vocabHighlight.tsx`; явные формы чипов в уроках записывать как основа (+ вросший слог), без отдельных окончаний.
