# Передача контекста и журнал работ

Этот файл — общий источник контекста для всех моделей, работающих с проектом. Его нужно читать в начале задачи и обновлять после значимых изменений, особенно после публикации.

Не добавлять сюда пароли, ключи, токены и другие секреты.

## Как обновлять файл

1. Новые устойчивые особенности проекта добавлять в раздел «Постоянный контекст».
2. Незавершённые задачи поддерживать в разделе «Открытые задачи».
3. Выполненную работу записывать в начало журнала: дата, результат, коммит, проверки и состояние production.
4. Не писать «выложено на прод», пока не проверены все применимые этапы:
   - коммит отправлен в `origin/main`;
   - deployment рабочего Vercel-проекта завершился успешно;
   - изменения контента синхронизированы с production Supabase;
   - рабочий домен открыт и показывает новые данные.

### Учебный контент

- Источником истины служат фотографии в `content/reference/inha_book_photo/`. Нельзя дополнять текст, словари или упражнения «по смыслу», если этого нет на фотографии или пользователь явно не попросил.
- Расшифрованный контент лежит в `content/reference/inha_book_content/`.
- `page_index` в `textbook_pages` сквозной в пределах всего учебника. Нельзя вычислять production-строку только по индексу; безопаснее использовать textbook slug, `lesson_number` и `page_number`.
- Уроки читаются приложением из Supabase, поэтому локальное изменение JSON само по себе не появляется даже в локальном браузере, если он подключён к старым данным базы.
- В одном тексте (и внутри раздела) переводной чип ставится только на первое вхождение слова; повторные вхождения того же слова не переводятся. Код уже дедуплицирует через `seenVocab` — в JSON слово указывать один раз в `vocab[]`.
- Рукописные словари нужно сохранять отдельно от локальных переводов слов, необходимых только конкретному упражнению.
- Иллюстрации `2급 4과`, `2급 5과` и `2급 6과` лежат в `img/` соответствующего урока и подключены к пяти разделам: 준비하기1, 준비하기2, 듣고 말하기, 읽고 말하기, 문화 이해하기. Раздел 말하기 остаётся без отдельной иллюстрации, как в уроках 2–3.
- Правило (с 2급 5과): в каждом разделе урока (`toc_section`) словарные слова всегда в одном `vocab_list`-блоке, а не раскиданы по нескольким страницам этого раздела — сразу собирать так при авторинге нового урока, а не чинить потом.
- Когда упражнение grammar_exercise — заполнение пропуска в РАЗНОМ предложении на каждый пункт (а не один общий шаблон с меняющимися словами), это не один блок с несколькими items, а несколько отдельных grammar_exercise-блоков (каждый — свой template с одним {0} и один item), с одинаковым exercise_title — так сделано в 2급 6과 연습하기4 (13 блоков на ㅅ-неправильные/правильные глаголы, нумерация 4-1…4-13 автоматическая).
- В `grammar_point.rules[]`: если форма зависит от 받침 — два отдельных пункта (без 받침 / с 받침), не одна строка через запятую. Если от 받침 не зависит — 받침 вообще не упоминать.
