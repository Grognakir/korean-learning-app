# Игра «Примерочная»: требования к изображениям

Обязательны для любой генерации картинок персонажей и одежды (Codex, Higgsfield и др.).
Картинки потом режутся на слои и надеваются друг на друга, поэтому отступать от правил нельзя.

## 1. Фон — главное правило

- Фон: **сплошной чистый белый `#FFFFFF`**, полностью непрозрачный.
- **Никогда не делать прозрачный фон** и не «изображать» прозрачность: никакой шахматки,
  шума, серых пятен, полупрозрачных пикселей. Белый фон в прозрачный превращается
  отдельно, скриптом, не генератором.
- Никаких теней на полу, свечения, ореолов, обводки или цветной каймы вокруг фигуры.
- Все промежутки внутри силуэта (между рукой и телом, между ногами) — тоже чистый белый.
- Формат PNG, RGB, размер ровно **1024×1536**.

## 2. Стиль

Ориентир — `public/images/clothing-game/test2/base.png` (утверждён пользователем).
Modern stylized 2D game character art: жирный чёрный контур с перепадом толщины,
жёсткий cel-shading (плоский цвет + одна резкая тень, без мягких градиентов),
вытянутые стилизованные пропорции, выразительное лицо. Без фотореализма,
без волос на теле, без аниме-стиля.

## 3. Совмещение кадров

- Все кадры одного персонажа делаются **редактированием `base.png`**, а не новой генерацией.
- Поза, масштаб и положение фигуры на холсте должны совпадать с `base.png`.
- Меняется только то, что указано в задаче (лицо или одна вещь).

## 4. Одежда

- Каждая вещь — отдельный кадр: редактирование `base.png`, на персонаже только эта вещь
  (плюс бельё из base).
- Вещь **строго белая** (белый + серые тени), без узоров и логотипов: цвет накладывается в игре.
- Исключения, которые не перекрашиваются, оговариваются в задаче явно (например, оправа очков).
- Если вещь надевается поверх другой (галстук на рубашку, пиджак на рубашку и галстук),
  нижние вещи рисуются **служебными цветами**, чтобы белую вещь можно было вырезать:
  рубашка — голубая `#9EC5E8`, галстук — бордовый `#7A1F2B`, брюки — тёмно-серые `#4A4A4A`.
  Белой в кадре всегда остаётся только одна, целевая вещь.
- Голова потом отрезается отдельным слоем для анимации: вещи не должны закрывать шею
  выше линии воротника, кроме головных уборов и очков.

## 4а. Иконки для витрины магазина

- Отдельные картинки, НЕ вырезка с персонажа: вещь «как в каталоге», без тела и манекена.
  Рубашка и пиджак — сложены или разложены плоско (flat lay), брюки — сложены или
  разложены, туфли — пара в три четверти, галстук — свободно лежит, очки — спереди, дужки сложены.
- Тот же стиль, что у персонажа (контур, cel-shading), вещь та же по фасону и деталям.
- Белый фон `#FFFFFF`, PNG RGB, **512×512**, вещь по центру с полями ~10%.
- Масштаб реалистичный относительно друг друга внутри одного набора: галстук заметно
  меньше рубашки, очки маленькие; не растягивать вещь на всю картинку.
- Перекрашиваемые вещи — строго белые (как в разделе 4), очки — в своём цвете.
- Путь: `public/images/clothing-game/<набор>/icons/<вещь>.png` + маска `<вещь>_mask.png`
  (вещь целиком залита `#FF00FF`) для вырезки.

## 5. Самопроверка перед сдачей (обязательно)

Запустить для каждого нового файла и перегенерировать всё, что не прошло:

```bash
python3 - <<'EOF'
import sys, glob
from PIL import Image
bad = False
for p in sorted(glob.glob("public/images/clothing-game/test2/*.png") + glob.glob("public/images/clothing-game/test2/stack/*.png")):
    im = Image.open(p)
    ok_size = im.size == (1024, 1536)
    rgba = im.convert("RGBA")
    w, h = rgba.size
    # рамка 8px по краям должна быть чисто белой и непрозрачной
    edge = [rgba.getpixel((x, y)) for x in range(0, w, 4) for y in list(range(8)) + list(range(h - 8, h))]
    edge += [rgba.getpixel((x, y)) for y in range(0, h, 4) for x in list(range(8)) + list(range(w - 8, w))]
    ok_bg = all(px[3] == 255 and min(px[:3]) >= 250 for px in edge)
    ok_alpha = rgba.getextrema()[3][0] == 255
    status = "OK" if ok_size and ok_bg and ok_alpha else "FAIL"
    bad |= status == "FAIL"
    print(f"{status}  {p}  size={im.size} white_edges={ok_bg} opaque={ok_alpha}")
sys.exit(1 if bad else 0)
EOF
```

В отчёте перечислить файлы, результат проверки и заметные расхождения с `base.png`.

## 6. Итоговые файлы — `public/images/clothing-game/prod/`

Всё, что идёт в игру, собирается в `prod/` (структура и порядок сборки — в `prod/README.md`).
Ручные обводки пользователя (`prod/masks/`) и исходники для них (`prod/sources/`) не перезаписывать
без его просьбы. `test/` и `test2/` — черновики и стопки.
