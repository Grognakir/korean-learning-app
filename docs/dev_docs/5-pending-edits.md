# 5. Отложенные правки

Сюда записываются правки, которые пользователь указал, но ещё не разрешил делать.

Правило для агента:

1. Если пользователь описывает правку и не говорит «сделай» / «выполни отложенные» — только добавить пункт сюда. Код, стили и контент не менять.
2. Делать пункты только после явной просьбы (все сразу, по номерам или по списку).
3. После выполнения пометить пункт как сделанный, коротко указать что изменилось, и не держать его в активном списке.

Формат пункта: дата, где (страница / DOM / файл, если известно), что сделать.
