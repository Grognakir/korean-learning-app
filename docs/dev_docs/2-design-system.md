# 2. Дизайн-система: источник стиля и типографика

## Источник визуального языка

**Решение:** переиспользовать визуальный язык (design language) проекта `korean_flashcards` — палитру, форму, характер — но не код компонентов. `korean_flashcards` — vanilla JS/CSS (один `app.js`, один `style.css`), у нового проекта другой стек (React + CSS Modules), поэтому переносится не разметка, а токены: цвета, тени, радиусы фиксируются как CSS-переменные в `styles/tokens.css` (папка уже заложена в структуре проекта в `0-mvp.md`).

### Извлечённые токены

| Токен | Значение | Роль |
|---|---|---|
| `--paper` | `#FAF6EE` | Фон приложения (тёплый, не белый) |
| `--paper-2` | `#F1EBDC` | Вторичный фон (панели навигации, неактивные поля) |
| `--ink` | `#1C1B19` | Основной текст, primary-кнопки |
| `--ink-soft` | `#57534A` | Вторичный текст |
| `--stone` | `#8A8478` | Третичный текст, подписи |
| `--line` | `#DDD5C2` | Границы, разделители |
| `--red` | `#C23B34` | Акцент 1 (часть тхэгык-мотива, ошибка) |
| `--blue` | `#1F4E8C` | Акцент 2 (часть тхэгык-мотива, ссылки/хайлайты) |
| `--green` | `#4C7A5E` | Успех/правильный ответ |
| `--amber` | `#B4802A` | Предупреждение |
| `--card-shadow` | `0 1px 2px rgba(28,27,25,.06), 0 8px 24px rgba(28,27,25,.08)` | Мягкая многослойная тень карточек/панелей |

Форма: скругления 12–20px на карточках и панелях, 100px (пилюля) на чипах и статус-бейджах.

**Культурная деталь, которую стоит сохранить:** красно-синяя градиентная кромка сверху карточки (`.taegeuk-edge`) — отсылка к тхэгык (태극) с корейского флага, переворачивается местами при флипе карточки (лицо/оборот). Небольшая деталь, но она — часть узнаваемости референса, стоит перенести как есть.

**Что не переносится буквально:** CSS-классы и HTML-разметка референса. Он написан без компонентного фреймворка, слепое копирование разметки в React-проект даёт нефункциональный гибрид — переносится намерение (тёплая бумажная палитра, мягкость, тхэгык-акцент), реализация — заново, средствами CSS Modules + токенов.

## Типографика и переключение шрифтов

Сейчас в референсе — только системные шрифтовые стеки (`-apple-system/Segoe UI/Roboto` для латиницы, `Apple SD Gothic Neo/Malgun Gothic/Noto Sans KR` для корейского через класс `.kr`), вебшрифты не подключены вовсе. Для новой фичи переключения шрифта нужен набор кандидатов на каждый язык плюс отдельный рукописный вариант для корейского.

### Русский / английский (кириллица + латиница)

| Шрифт | Характер | Источник |
|---|---|---|
| **Inter** | Нейтральный, максимально читаемый UI-гротеск, отличная кириллица | Google Fonts |
| **Golos Text** | Геометричный гротеск с кириллицей как родной (не адаптация под латиницу задним числом), тёплый и современный — хорошо ложится на «бумажную» палитру | Google Fonts |
| **PT Serif** | Книжный, тёплый serif (ParaType) — ощущение учебника, а не приложения; для режима чтения примеров/значений | Google Fonts |
| **Lora** | Гуманистический serif с полной поддержкой кириллицы — альтернатива PT Serif, чуть более современный ритм | Google Fonts |

Рекомендация: **Inter** как шрифт по умолчанию (безопасный, универсальный), **Golos Text** и **PT Serif/Lora** — как два разных «характера» в переключателе (один гротеск-альтернатива, один serif-альтернатива) — так выбор ощущается осмысленным, а не шумом из десяти похожих гротесков.

### Корейский

| Шрифт | Характер | Источник |
|---|---|---|
| **Pretendard** | Де-факто стандарт современных корейских интерфейсов; вариативный шрифт (variable font) с огромным диапазоном начертаний, метрики близки к системному Apple SD Gothic Neo — плавная замена текущего системного стека без «скачка» в характере | `@fontsource/pretendard` (npm) — не в каталоге Google Fonts |
| **Noto Sans KR** | Гарантированное CJK-покрытие, самый простой вариант подключения | Google Fonts |
| **Noto Serif KR** | Книжный (мёнджо-стиль), пара к PT Serif/Lora для «читательского» режима | Google Fonts |

Рекомендация: **Noto Sans KR** — самый дешёвый способ дать выбор шрифта уже в MVP (ноль доп. инфраструктуры, тот же `next/font/google`, что и для остальных). **Pretendard** — апгрейд по умолчанию, если нужен более современный/полированный вид, чем системный стек: чуть дороже подключить (self-host через `@fontsource`), но ощутимо лучше по качеству.

### Рукописный шрифт для корейского

| Шрифт | Характер | Комментарий |
|---|---|---|
| **Nanum Pen Script (나눔손글씨 펜)** | Рукописный, но разборчивый | **Рекомендую как основной** — из рукописных корейских шрифтов на Google Fonts самый читаемый, тёплый и личный характер без потери узнаваемости букв |
| **Nanum Brush Script (나눔손글씨 붓)** | Кистевой, декоративный | Хорош для заголовков/акцентов, но кистевые росчерки при мелком размере могут смазывать различимость 받침 (батчим, конечных согласных) — не для основного текста карточки |
| **Gaegu** | Округлый, «детский» | Третий вариант характера, если хочется более игривый тон |

**Важная оговорка как дизайнера:** рукописный шрифт — это правильно держать опциональным (как и задумано — переключатель, а не замена дефолта). Для человека, который ещё учится распознавать форму хангыля, каноничные печатные буквы должны оставаться шрифтом по умолчанию — рукописный вариант хорош как мотивационная/эстетическая опция, но не должен быть тем, с чего начинается знакомство с новым словом.

### Техническая схема подключения

Все перечисленные шрифты, кроме Pretendard, есть в каталоге Google Fonts — подключаются через `next/font/google`. Важное следствие для офлайн-режима (уже описанного в `0-mvp.md` и `1-cicd-and-testing.md`): `next/font` самостоятельно скачивает и самохостит шрифты на этапе сборки — приложение не делает рантайм-запрос к серверам Google при загрузке, шрифт становится частью бандла и кэшируется service worker'ом как обычный статический ассет. Переключение шрифтов не создаёт новой зависимости от сети в офлайне.

Pretendard в каталог Google Fonts не входит — подключается через пакет `@fontsource/pretendard` + `next/font/local`, либо ручной self-host файлов шрифта. Технически то же свойство (самохостится, доступен офлайн), просто другой путь установки.

Переключатель шрифтов реализуется как CSS-переменные поверх уже запланированных токенов (`--font-latin`, `--font-kr`), переключаемые через `data`-атрибут на `:root` (например `data-font-kr="pretendard"`) — сохранённое значение хранится в `profiles` пользователя или, для гостя, в `localStorage`.

## Что дальше

Это решение по стилю, не по скоупу — переключение шрифтов в текущем `0-mvp.md` не значится как фича MVP. Если берёшь её в MVP (как ранее с офлайн-записью прогресса) — стоит явно добавить в «Скоуп MVP» и roadmap, а не оставлять подразумеваемым.
