# 4. Контент учебника: формат файлов и разметка блоков

Статус: черновик, действует с ADR-0002. Описывает, как контент, извлечённый из фото учебника, кладётся в файлы до того, как появится импорт в `textbook_pages` (см. `3-dictionary-and-learning.md`, раздел 2.2).

## Организация файлов

Один файл — один урок. Файлы лежат рядом с уже существующими `inha_book_1_photo/`, `inha_book_1_audio/`, `inha_book_1_book/` — четвёртая параллельная папка:

```
docs/reference/
  inha_book_1_photo/       # уже есть — фото страниц
  inha_book_1_audio/       # уже есть — 101.mp3 ... 164.mp3
  inha_book_1_book/        # уже есть — PDF-пилот + иллюстрации
  inha_book_1_content/     # новое — контент по урокам, JSON
    lesson_01.json
    lesson_02.json
    ...
    lesson_16.json
    book_frontmatter.json  # страницы вне уроков: 차례 (оглавление книги), 듣기 지문, 모범 답안, 문법 설명, 색인
```

Книжное оглавление (страница 차례) не принадлежит ни одному уроку — оно уходит в `book_frontmatter.json`, а не в `lesson_01.json`, даже несмотря на то, что было сфотографировано вместе с уроком 1 (`photo_0`).

Имя файла — `lesson_{NN}.json`, `NN` с ведущим нулём (`01`…`16`), чтобы сортировка по имени файла совпадала с порядком уроков.

## Структура одного файла урока

```json
{
  "textbook_id": "inha_book_1",
  "lesson_number": 1,
  "title": "인사와 소개",
  "pages": [
    {
      "page_number": null,
      "page_role": "lesson_opening",
      "source_photo": "photo_1",
      "blocks": [ /* ... */ ]
    },
    {
      "page_number": 10,
      "page_role": "content",
      "source_photo": "photo_2",
      "blocks": [ /* ... */ ]
    }
  ]
}
```

- `page_number` — как напечатано внизу страницы; `null`, если на странице номера нет (титульная страница урока).
- `source_photo` — какое фото (`photo_0`…`photo_N` из `inha_book_1_photo/`) было источником; сохраняется ради прослеживаемости — если позже найдётся ошибка транскрибирования, видно, какое фото перепроверять.
- `blocks` — упорядоченный список блоков страницы, типы — ниже. Один и тот же порядок, что и в оригинале сверху вниз.

Каждый блок страницы (кроме `lesson_toc`) обязательно несёт два поля, нужные для навигации по разделам урока:

- `id` — стабильный слаг блока в пределах урока (например `grammar-1`, `text-greeting-dialogue`). Это то, на что ссылается `lesson_toc.sections[].items[].block_ref` (см. ниже) и якорь для перехода/скролла на странице раздела.
- `toc_section` — какому `key` из `lesson_toc.sections` принадлежит блок (например `"준비하기 1"`). Определяет, на странице какого раздела блок показывается.

Если блок ещё не относится ни к какому размеченному разделу (редко, но возможно на переходном этапе авторства) — оба поля можно опустить, но тогда блок нигде не появится в разделах, только по прямому запросу.

При импорте в `textbook_pages` (ADR-0002) каждый объект из `pages` становится одной строкой: `textbook_pages.content = {"blocks": [...]}`, `page_number`/`lesson_number` — обычные колонки.

## Типы блоков

### `lesson_toc` — оглавление/состав урока

Список подразделов урока (준비하기, 말하기, 듣기...) с их темами — то, что раньше на бумаге называлось «страницей состава урока». Каждый пункт — не просто текст-ярлык, а ссылка на конкретный блок контента (`block_ref` = `id` того блока), который открывается при клике: страница раздела (`toc_section`), проскроллено к самому блоку. Если для темы ещё не авторен соответствующий блок — `block_ref: null`, пункт показывается неактивным.

```json
{
  "type": "lesson_toc",
  "sections": [
    { "key": "준비하기 1", "items": [
      { "label": "인사하기", "block_ref": "text-greeting-dialogue" },
      { "label": "N입니다 / N입니까?", "block_ref": "grammar-1" },
      { "label": "N이/가", "block_ref": "grammar-2" },
      { "label": "N은/는①", "block_ref": "grammar-3" }
    ] },
    { "key": "말하기", "items": [
      { "label": "자기소개하기", "block_ref": null }
    ] }
  ]
}
```

### `text` — связный текст (диалог или отрывок)

Помечается, к какому разделу урока относится, к какому упражнению (если это пример-образец для тренировки) и какое аудио ему соответствует. Если у диалога есть заголовок и своя иллюстрация (типичная страница «картинка сверху + аудио + диалог») — они встраиваются прямо в этот блок через `title`/`illustration`, а не заводятся отдельным `illustration`-блоком рядом: так заголовок, картинка (без подписи), аудио и текст рендерятся одной единой карточкой.

```json
{
  "type": "text",
  "title": "인사하기",
  "illustration": {
    "storage_path": "illustration_0_handshake.png",
    "original_kind": "photo"
  },
  "text_kind": "dialogue",
  "section": "준비하기1",
  "exercise_ref": null,
  "audio_id": "101",
  "speakers": ["왕루", "자르갈"],
  "lines": [
    { "speaker": "왕루", "text": "안녕하십니까? 처음 뵙겠습니다." },
    { "speaker": "자르갈", "text": "네, 안녕하십니까? 저는 자르갈입니다. 처음 뵙겠습니다. 이름이 무엇입니까?", "emphasized": ["이름이 무엇입니까?"] }
  ]
}
```

- `title` — необязательный заголовок текста/диалога (например название упражнения на говорение, «교실 물건을 말하기» и т.п.); если у страницы такого заголовка нет — поле опускается.
- `illustration` — необязательная встроенная иллюстрация: `storage_path` (имя файла в `inha_book_1_book/image/`, `null` если ещё не найдена/не сгенерирована) и `original_kind` (`photo` | `illustration`). У встроенной иллюстрации подписи (`caption`) нет намеренно — она показывается без caption, в отличие от отдельно стоящего `illustration`-блока (см. ниже), где caption обязателен. Отдельный `illustration`-блок по-прежнему используется для иллюстраций, не привязанных к конкретному тексту (например пары иллюстрация+фраза на страницах приветствий).
- `text_kind`: `dialogue` (реплики по ролям) | `passage` (сплошной текст без ролей) | `example_line` (короткий образец внутри блока упражнения — обычно не отдельный `text`-блок, а часть `grammar_exercise.example`, см. ниже).
- `audio_id` — номер трека без `.mp3`, ссылается на файл в `inha_book_1_audio/`. `null`, если для этого текста аудио нет.
- `exercise_ref` — если текст является диалогом-образцом к конкретному `grammar_exercise` (сейчас образцы дублируются внутри самого блока упражнения — см. ниже, — но если понадобится связать текст с упражнением напрямую, сюда идёт `id` того блока).
- `emphasized` — фразы, подчёркнутые в оригинале ручкой (это разбор ключевых конструкций студентом, а не посторонняя пометка) — сохраняются, в отличие от рукописного перевода на полях, который в PDF-пилоте не переносился.

### `vocab_list` — слова для повторения (сноска)

```json
{
  "type": "vocab_list",
  "title": "Слова к 준비하기1",
  "related_text_ref": null,
  "items": [
    { "ko": "처음", "translation_ru": "впервые" },
    { "ko": "뵙다", "translation_ru": "смотреть (вежл.)" }
  ]
}
```

`related_text_ref` — необязательная ссылка на блок `text`, к которому относится список (по индексу блока на странице или по `id`, если блокам присвоены id).

### `grammar_point` — грамматика с примерами

```json
{
  "type": "grammar_point",
  "pattern": "N입니다 / N입니까?",
  "section": "1",
  "explanation": null,
  "examples": [
    "가: 이름이 무엇입니까?\n나: 저는 왕루입니다.",
    "가: 왕루 씨는 어느 나라 사람입니까?\n나: 저는 중국 사람입니다."
  ]
}
```

`section` — номер, под которым конструкция идёт в уроке («1.», «2.», «3.» на страницах грамматики) — печатная нумерация оригинала, для человека. `explanation` — `null`, если в этом учебнике на этой странице только образец без текстового пояснения (обычно так и есть на уровне 1급); поле оставлено на будущее, если понадобится добавить объяснение самостоятельно.

### `grammar_exercise` — упражнение по грамматике

```json
{
  "type": "grammar_exercise",
  "exercise_title": "연습하기1",
  "grammar_ref": "grammar-1",
  "prompt": "다음과 같이 이야기해 보십시오.",
  "example": {
    "given": ["왕루", "자르갈"],
    "dialogue": [
      "가: 처음 뵙겠습니다. 저는 왕루입니다. 이름이 무엇입니까?",
      "나: 제 이름은 자르갈입니다. 만나서 반갑습니다.",
      "가: 만나서 반갑습니다."
    ]
  },
  "items": [
    { "given": ["아멜리", "파하드"] },
    { "given": ["최수지", "오위노"] }
  ]
}
```

`grammar_ref` — `id` блока `grammar_point`, к которому относится упражнение (не печатный номер — стабильная ссылка на блок, переживающая нумерацию оригинала). `items` — варианты подстановки (то, что студент проговаривает по образцу `example`), без готовых ответов — они у него и так открыты в учебнике (в отличие от будущего интерактивного режима, где ответ можно будет скрывать/проверять).

### `hint` — подсказки (표현-блоки и похожие врезки)

```json
{
  "type": "hint",
  "hint_kind": "expression",
  "related_text_ref": "text-greeting-dialogue",
  "items": [
    { "kind": "phrase", "text": "처음 뵙겠습니다", "translation_ru": "Очень приятно познакомиться (при первой встрече)" },
    { "kind": "phrase", "text": "만나서 반갑습니다", "translation_ru": "Рад(а) встрече" },
    { "kind": "phrase", "text": "어디에서 왔습니까?", "translation_ru": "Откуда вы приехали?" },
    { "kind": "pattern", "text": "N에서 왔습니다", "translation_ru": "Я приехал(а) из N — шаблон: [место] + 에서 왔습니다" },
    { "kind": "pattern", "text": "어느 N: 어느 나라 사람입니까?", "translation_ru": "Какой/какая N — шаблон; пример «어느 나라 사람입니까?» = «Из какой вы страны?»" }
  ]
}
```

`hint_kind`: `expression` (표현-врезка) | `greeting_phrase` (короткая фраза-подпись под иллюстрацией на страницах приветствий/благодарностей) | другое — по мере появления новых видов врезок в следующих уроках список расширяется, это не закрытый enum.

Каждый элемент `items` — объект `{ text, translation_ru, kind }`, не голая строка:
- `kind: "phrase"` — готовое выражение, можно использовать как есть (например «처음 뵙겠습니다»).
- `kind: "pattern"` — конструкция с плейсхолдером (буква `N` вместо подставляемого слова), даже если внутри самого текста после двоеточия идёт готовый пример применения (как в «어느 N: 어느 나라 사람입니까?») — наличие рабочего примера не делает элемент `phrase`, разделение идёт по тому, *представлен* ли элемент как шаблон для подстановки или как готовая фраза.
- `translation_ru` — обязателен, используется для перевода по наведению/тапу в интерфейсе (тот же принцип, что у `vocab_list.items[].translation_ru`).

`related_text_ref` — если `hint` относится к конкретному `text`-блоку (например 표현-врезка после диалога) — `id` этого блока; в интерфейсе такой `hint` крепится под текстом единой карточкой, а не отдельным блоком (см. `related_text_ref` у `vocab_list` — тот же принцип).

### `illustration` — иллюстрация

```json
{
  "type": "illustration",
  "storage_path": "illustration_0_handshake.png",
  "caption": "Двое знакомятся и пожимают друг другу руки",
  "original_kind": "photo",
  "pair_id": null
}
```

- `storage_path` — имя файла внутри `inha_book_1_book/image/` (после переноса в Supabase Storage — путь в бакете). `null`, если иллюстрация ещё не найдена/не сгенерирована — тогда `caption` работает как техническое задание на неё, ровно как заглушки в PDF-пилоте.
- `original_kind`: `photo` | `illustration` — в оригинале это фотография или рисованная иллюстрация (не всегда важно, но иногда пригодится).
- `pair_id` — если иллюстрация идёт в паре с конкретной фразой (`hint` с `hint_kind: "greeting_phrase"`) — общий идентификатор у обоих блоков, чтобы при рендере они держались вместе как одна карточка.

### `reference_table` — справочная таблица

```json
{
  "type": "reference_table",
  "title": "나라 이름",
  "columns": ["한국", "중국", "일본", "몽골", "베트남", "캄보디아", "필리핀", "러시아", "카자흐스탄", "키르기스스탄", "케냐", "사우디아라비아", "영국", "프랑스", "미국", "캐나다"],
  "note": "в оригинале рядом с каждой страной — флаг"
}
```

## Сводка: что чем помечается

| Что на странице | Тип блока |
|---|---|
| Оглавление/состав урока | `lesson_toc` |
| Диалог или связный текст | `text` (+ `audio_id`, `exercise_ref`, `section`) |
| Список слов для повторения | `vocab_list` |
| Грамматика с примерами | `grammar_point` |
| Упражнение на грамматику | `grammar_exercise` (+ `grammar_ref`) |
| Подсказка/врезка (표현 и т.п.) | `hint` |
| Фото или рисунок | `illustration` |
| Справочная таблица | `reference_table` |

Список типов не закрыт — если в следующих уроках встретится страница, которая не ложится ни в один из них (например, упражнение на аудирование с несколькими вопросами, или текст для чтения на целую страницу), в этот документ добавляется новый тип по тому же принципу: явное поле `type`, явные ссылки (`*_ref`) на то, с чем блок связан, а не жёсткая привязка к позиции на странице.
