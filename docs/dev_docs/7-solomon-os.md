# Solomon OS — игровая ОС и приложения

План, согласованный с пользователем 2026-10-30. Работа идёт по этапам; следующий этап начинается
только после того, как пользователь принял предыдущий.

## Идея

Внутри приложения — «телефон» героя с вымышленной ОС **Solomon OS**. Каждое приложение — способ
практиковать корейский в живом контексте. Первое приложение — мессенджер, первая собеседница — 지아.
Нынешний звонок 지아 (`src/features/lessonSticker/story/`) со временем становится приложением «звонки».

## История (пишет пользователь)

Герой — парень, который ради девушки переехал в Корею. Ходит на курсы корейского, подрабатывает где
придётся, ищет нормальную работу, знакомится с людьми, общается с девушкой. Потом случается
апокалипсис: нужно спасаться, решать задачи, взаимодействовать с миром, искать выход и развиваться.

Сюжетные тексты — только от пользователя (или с его явного утверждения); учебная лексика и грамматика —
по урокам учебника. Мирная часть естественно ложится на 1급–2급 (быт, покупки, работа), апокалипсис —
на более поздние уровни.

## Стиль

Зелёный «хакерский» терминал: смесь интерфейса Kali Linux (чёрный фон, моноширинный шрифт, верхняя
панель, терминал, окна с тонкой рамкой), эстетики Некронов из Warhammer 40k (зелёное свечение, «мёртвая»
техника, угловатые рамки, глифы) и «матричного» дождя — как уже сделано в звонке 지아. Логотипы и
названия Kali, Warhammer и т. п. не используются: только общий стиль, своё имя и свой знак.

## Этап 1. Каркас ОС

- Загрузка: строки бута в терминале (`[ OK ] …`, «시스템 부팅 중…») → экран входа героя.
- Рабочий стол: иконки приложений, верхняя панель с игровым временем и датой по-корейски
  (오후 3:20 · 10월 30일), сигнал, батарея.
- Окна приложений на весь экран телефона, кнопки «назад» и «домой».
- Уведомления: баннер сверху («지아: 뭐 해요?») и счётчики на иконках.
- Работает только мессенджер; остальные иконки (звонки, карта, магазин, банк…) серые с замком —
  открываются по сюжету.
- Интерфейс по-корейски, перевод — кнопкой RU, как в звонке.
- iPhone: безопасные зоны, без горизонтальной прокрутки, проверка на 375px.

## Этап 2. Мессенджер с 지아

- Список чатов (пока один — 지아) и переписка: пузыри, «печатает…», время, 읽음.
- Ответ — **выбор из 2–3 готовых вариантов**. Странный или неверный ответ даёт реакцию 지아,
  сюжет продолжается.
- Тап по сообщению — перевод, тап по слову — перевод слова.
- Переписка — файл данных (шаги: сообщение / варианты ответа / пауза / событие), как эпизоды звонка.
- Прогресс сохраняется: переписка продолжается с того же места.
- Первая переписка — пролог из истории пользователя.

## Порядок работы

1. Интерактивный макет одним HTML (как Примерочная) — пользователь проверяет на iPhone, правим стиль.
2. Перенос в приложение отдельным полноэкранным разделом.
3. Подключение пролога, который пишет пользователь.

Оценка: каркас ~80–120 тыс. выходных токенов, мессенджер ~120–200 тыс.
