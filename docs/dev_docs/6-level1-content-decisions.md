# 6. 1급: решения по переносу уроков

Журнал спорных мест при переносе `새인하한국어1` (1급) из фото в `content/reference/inha_book_content/1급_lesson_NN/`. Нужен, чтобы позже понять, почему блок устроен именно так, и при необходимости переделать. Формат и общие правила — в `4-textbook-content-authoring.md`; хронология работ — в `docs/AGENT_HANDOFF.md`.

Порядок работы: фото уроков лежат в `content/reference/inha_book_photo/1급_N과/` (в git не попадают). Уроки переносятся по одному, следующий — только по явной просьбе пользователя. Для каждого урока: дословный перенос → импорт локально → проверка в браузере → коммит, деплой, точечный импорт в production (`--k1-lesson-N-only`).

Новые записи добавлять вниз, по одному разделу на урок.

## Общие решения (действуют для всех уроков 1급)

- **Упражнения со свободным ответом** (в книге — пустые линии `______`): текстовый блок с `exercise_title`, без ответов. Ответы не придумываются. Упражнения, где ответ однозначен, — обычный `grammar_exercise`, и каждый пункт проверяется временным тестом «пункт принимает свои ответы».
- **Рукописные записи пользователя** на фото (перевод слов, образцы текстов, пометки на полях) в учебный контент не переносятся. Исключение — сверка правильных ответов (карандашные ответы на фото сверяются с текстом).
- **Слова со стикеров** на полях: корейские слова напечатаны в книге, русские переводы добавлены при переносе (это отмечено в `source_note` у `vocab_list`). Один `vocab_list` на раздел урока.
- **Правильные ответы к аудированию** ставятся только по тексту `듣기 지문` (`1급_듣기_지문`) и/или по схеме из книги; без них — `correct: null`. Текст `듣기 지문` кладётся в `transcript` блока.
- **Имена собственные** со стикеров и схем (названия корпусов, города, имена людей) в переводные чипы не выносятся.
- **Картинки из книги**, без которых вопрос теряет смысл (схемы, карты), вырезаются из фото в `img/` урока и подключаются блоком `illustration`. Остальные фото и рисунки не копируются.
