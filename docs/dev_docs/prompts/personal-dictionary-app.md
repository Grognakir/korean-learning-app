# Задача для Codex: приложение «Словарь» в Solomon OS и тренировка из него

Ты работаешь в репозитории `korean-learning-app` (Next.js, приложение для изучения корейского; пользователь — русскоговорящий). Сделай новое приложение Solomon OS «Словарь» — личный список слов, которые пользователь сам записывает для заучивания, — карточный тренажёр внутри него и тему «Мой словарь» в тренажёре слов мессенджера. Ничего не коммить, не пушить, не деплой: пользователь сделает это сам.

## 1. Идея

Пользователь сам записывает корейские слова и переводы. Словарь — **только то, что записал он**: никаких готовых слов, подсказок, автодополнения и предзаполнения. Все тренировки (в приложении и в мессенджере) берут слова и переводы из этого списка и больше ниоткуда.

## 2. Приложение «Словарь»

Новое приложение в реестре: `id: "dict"`, `ko: "단어장"`, `ru: "Словарь"`, своя заполненная иконка в стиле остальных (книжка или блокнот с закладкой; цвета и штрихи из токенов, как у иконок `notes`/`viewer` в `icons.tsx`). Окно по умолчанию 860×640, минимум 360×440. Иконка попадает на рабочий стол общим механизмом (проверь `iconGrid.ts`: уже сохранённые раскладки пользователя не должны ломаться, новая иконка просто встаёт в свободную ячейку; существующие тесты сетки проходят).

### 2.1 Экраны

Две вкладки в шапке окна: «단어 / Слова» и «카드 / Карточки». Корейская надпись — основная, русская — мелкая подпись рядом (`--soft`), видна всегда.

**Слова** (по умолчанию):
- Компьютер: две колонки — слева список слов, справа форма добавления/редактирования. Телефон: список на весь экран, кнопка «+» (круглая, `--green` с `--ink`) открывает форму листом поверх списка.
- Форма: поле «한국어 · Корейский» (обязательное), поле «번역 · Перевод» (необязательное), кнопки «추가 / Добавить» (при редактировании «저장 / Сохранить»), «취소 / Отмена». Enter в любом поле отправляет форму; после добавления форма очищается, фокус возвращается в поле корейского (быстрый ввод подряд). Подсказки-плейсхолдеры (не данные): «예: 사과», «например, яблоко».
- Перевод может содержать несколько вариантов через запятую или точку с запятой (запятые внутри скобок не разделяют): «красный, красного цвета». Первый вариант — основной, он показывается как ответ в тренировках и вариантах выбора; все варианты принимаются при вводе.
- Корейское поле: допускается несколько вариантов через «/» (например, «학교/학교에»). Первый — основной; при вводе по-корейски принимается любой.
- Проверки формы: в корейском поле обязательно есть хотя бы один хангыль (иначе сообщение «한국어로 써 주세요. / Напишите по-корейски.»); в переводе хангыля быть не должно (иначе «번역은 러시아어로. / Перевод — по-русски.»); пробелы по краям обрезаются, внутри схлопываются; длина корейского до 60 символов, перевода до 120.
- Повтор: если такое корейское слово уже есть (сравнение после нормализации — NFC, пробелы убраны, регистр латиницы не важен), форма не создаёт дубль, а сообщает «이미 있어요. / Такое слово уже есть.» и предлагает открыть существующее для правки.
- Слово без перевода можно сохранить: оно видно в списке с меткой «без перевода», в тренировки не попадает.
- Список: поле поиска («검색 / Поиск»: по корейскому и по переводу), сортировка: сначала новые / по алфавиту (переключатель), счётчик «всего N · в тренировке M». У каждого слова: корейское крупно (класс `kr`), перевод `--soft`, у слов со статистикой — маленький индикатор «верно / ошибок». Нажатие открывает слово в форме; рядом кнопка удаления «삭제» с подтверждением «정말 삭제할까요? / Удалить это слово?» («삭제» и «취소» в подтверждении).
- Пустой список: «아직 단어가 없어요. / Пока нет слов. Добавьте первое.» и стрелка/выделение на форму.

**Карточки** (тренировка прямо в приложении):
1. Экран выбора. Три режима плитками:
   - «한 → 러 · 고르기» — Корейский → Русский, выбор ответа;
   - «러 → 한 · 고르기» — Русский → Корейский, выбор ответа;
   - «러 → 한 · 쓰기» — Русский → Корейский, вписывание ответа.
   Охват: «Все слова» / «Только сложные» (ошибок больше, чем верных ответов). Кнопка «시작 / Начать» неактивна, пока в охвате меньше слов, чем нужно (минимум 2 слова с переводом; для режимов выбора достаточно 2 — вариантов будет `min(4, N)`; для вписывания хватает 1), рядом пояснение, чего не хватает.
2. Карточка: по центру крупная карточка (панель `--win`, рамка `--line`, радиус 14px, тень лёгкая) с вопросом: корейское слово (в режиме 한→러) или русский перевод (в режимах 러→한), размер 28–34px. Над карточкой строка прогресса: «3 / 12 · 정답 2» и справа кнопка «그만하기 / Закончить» (всегда видна). Ниже — варианты ответа кнопками (режимы выбора) или поле ввода с кнопкой Enter (вписывание). Для ввода по-корейски поддерживается обычная корейская раскладка телефона/системы; никаких своих клавиатур.
3. После ответа карточка показывает результат: верный ответ — подсветка `--green` с текстом `--ink`; неверный — рамка `--red`, внизу строка «정답: … / Правильно: …», у вписывания показан и мой ввод. Кнопка «다음 / Дальше» (Enter тоже). Автоперехода нет.
4. Круг: все слова охвата по одному разу в случайном порядке. В конце экран итога «끝! {верно}/{всего}» с кнопками «틀린 단어 다시 / Повторить ошибки», «한 바퀴 더 / Ещё круг», «나가기 / Выйти»; ниже список слов с ошибками. Состояние сессии в памяти (при закрытии окна теряется), а статистика слов сохраняется.
5. Правила проверки:
   - выбор: один верный и до трёх неверных из других слов словаря (с той же стороны: для 한→러 — русские основные переводы, для 러→한 — корейские основные написания), без повторов; порядок случайный;
   - вписывание (русский → корейский): сравнение корейского после NFC и удаления всех пробелов; принимается любой из вариантов через «/»; опечатки не прощаются (показывается правильный ответ);
   - ввод русского (в мессенджере, см. п. 3): нормализация и допуск одной опечатки так же, как уже сделано в тренажёре слов мессенджера (используй те же функции, не копируй).

### 2.2 Стиль

Оформление строго по `docs/dev_docs/8-agent-conventions.md` и в духе `Notes`/`Calendar` и мессенджера: только токены `var(--…)`; окна, списки и кнопки как существующие (`.reply`-кнопки: фон `#14241a`, рамка `--line`, радиус 8, наведение `--green` + `--ink`); поля ввода: фон `--win2`, рамка `--line`, радиус 8, фокус — рамка `--mid`, текст `--text`, высота не меньше 40px на телефоне; основная кнопка `--green` + `--ink`; опасное действие — текст `--red`; корейский текст с классом `kr`. Анимации короткие, с `prefers-reduced-motion`. Телефон 375px: без горизонтальной прокрутки, безопасные зоны, поле ввода не под клавиатурой, всё нажимается пальцем.

## 3. Мессенджер: тема «Мой словарь»

В тренажёре слов мессенджера (сценарий «Хочу повторить слова» → «Какие слова?») к теме «Одежда и цвета» добавляется вторая: **«내 단어장» / «Мой словарь»**. Остальной сценарий для неё тот же (документ → «Я готов» → выбор режима → вопросы по-русски «Что значит «…»?» → круги до «Закончить»), со следующими отличиями:

- Тема строится из словаря при выборе темы: берутся слова с переводом. Нужно минимум 2 слова. Если слов меньше, 지아 отвечает: «단어장에 단어가 더 필요해요. 단어장 앱에서 추가해 줘요.» / «В словаре мало слов. Добавь ещё в приложении «Словарь» (нужно минимум 2 слова с переводом).» — и возвращает к выбору темы.
- **Слова фиксируются в беседе на момент начала** (копия в состоянии беседы). Правка и удаление слов во время тренировки её не ломают; выбор вариантов и проверка работают по копии.
- Документ-вложение для этой темы строится автоматически: «내 단어장 · 단어장», один раздел «Слова», строки «корейское — основной перевод» в порядке добавления. Используй тот же просмотр документов, что и для темы одежды.
- Группа слов в теме одна, варианты выбора берутся из других слов словаря; при меньше чем 4 словах вариантов `min(4, N)`.
- Ответы в этой теме обновляют статистику слов в словаре (верно/ошибка), так же как в карточках приложения.
- Остальное (60 минут жизни беседы, плашка «Отработка темы «Мой словарь»», круги, кнопка «Закончить», итог) работает так же, как для темы одежды; подписи плашки и итога берут название темы.

## 4. Данные и хранение

- Только локальное хранилище через `OsStore` (`useOsStore()`), ключ `dictionary`. Структура (`v: 1`): массив слов `{ id, ko, ru, createdAt, updatedAt, ok, fail, lastAt? }`; `ko` и `ru` хранятся как введены (после обрезки и схлопывания пробелов), разбор вариантов — при чтении (функции, не поля). Максимум 2000 слов; при достижении предела форма сообщает «가득 찼어요. / Словарь заполнен.».
- Структуру существующих ключей хранилища (`chat`, `wordTrainer`, `wordTrainerStub` и др.) обратно несовместимо не менять.
- Серверных запросов, Supabase и ИИ нет. В словарь ничего не добавляется автоматически (ни из уроков, ни из тренажёров).

## 5. Файлы (предложение)

`src/features/solomonOs/dictionary/`:

- `answers.ts` — проверка корейского ответа, сборка вариантов выбора для обоих направлений (можно использовать общие функции тренажёра слов, если подходят);

- `Dictionary.tsx` (окно, вкладки), `WordList.tsx`, `EntryForm.tsx`, `Flashcards.tsx`;
- `Dictionary.module.css` — стили только на токенах.

Правки в существующих файлах — минимальные: `apps.ts` (+`AppId "dict"`), `icons.tsx` (+иконка), `SolomonOs.tsx` (показ приложения), тренажёр слов (`wordTrainer/*` и подключение в `Messenger.tsx`) — тема «Мой словарь» из словаря и копия слов в состоянии беседы.

## 7. Тесты и проверка (обязательно)

Новые тесты в `tests/`:
1. Чистая логика словаря: разбор вариантов (запятые внутри скобок, `;`, `/`), нормализация и поиск дублей (пробелы, NFC, регистр латиницы), проверки формы (нет хангыля, хангыль в переводе, длины), добавление/правка/удаление, предел 2000, статистика, слово без перевода не попадает в тренировку.
2. Проверка ответов: 한→러 и 러→한 в выборе (один верный, без повторов, `min(4, N)` при малом числе слов), вписывание по-корейски (пробелы, варианты через «/», опечатка не прощается).
3. Сессия карточек: круг покрывает слова охвата по одному разу, «Только сложные», повтор ошибок, итог, «Закончить» в любой момент.
4. Компонент приложения: добавление слова (включая быстрый ввод подряд), дубль, слово без перевода, поиск, правка, удаление с подтверждением, пустое состояние; данные переживают перемонтирование; три режима карточек от начала до итога.
5. Мессенджер: тема «Мой словарь» в выборе, сообщение о нехватке слов (меньше 2), беседа держит копию слов (правка и удаление в словаре не ломают вопросы), статистика обновляется, плашка после 60 минут называет тему.
6. Иконка «단어장» встаёт на рабочий стол, не ломая раскладку; существующие `tests/solomon-*.test.ts(x)` проходят без изменений.

Команды: `npx tsc --noEmit`, `npx eslint src/features/solomonOs tests`, `npx vitest run`.

Визуальная проверка: страница ОС (`/os`) требует вход; пароли не вводи и не ищи. Если открыть интерфейс не получилось, так и напиши и опиши, что проверено тестами. Если открыть удалось, проверь 375px: нет горизонтальной прокрутки, форма и ввод ответа не под клавиатурой, список прокручивается.
